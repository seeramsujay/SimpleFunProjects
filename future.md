# SimpleFunProjects: Future Roadmap & Interactive Extensions

SimpleFunProjects celebrates nostalgic, zero-dependency command-line algorithmic games. This roadmap details modern terminal user interface (TUI) upgrades and expanded game engines.

---

## 1. Modern Terminal User Interfaces (TUI)

- **Rich & Textual TUI Engine**:
  - Implement an optional enhanced visual mode using `rich` and `textual`, adding interactive terminal widgets, keyboard hotkeys, and dynamic ANSI color palettes.
- **Cross-Platform Audio Synth**:
  - Add optional 8-bit retro sound effects (beeps and melodic game fanfares) via native OS terminal bells or lightweight audio synthesizers.

---

## 2. Expanded Retro Game Library

- **Classic Text Adventure & Roguelike**:
  - Add procedural dungeon-crawler mini-engine with ASCII maze generation and turn-based combat.
- **Conway's Game of Life Cellular Automaton**:
  - Implement real-time terminal Game of Life simulation with customizable initial seed states and glider configurations.
- **Mastermind & Wordle Terminal Clones**:
  - Add deductive logic games with ANSI feedback grids and streak trackers.

---

## 3. Web & Distribution Channels

- **Pyodide WebAssembly Playground**:
  - Deploy zero-install web versions of the scripts directly to GitHub Pages using WebAssembly and Pyodide, allowing browser play without local python installation.
